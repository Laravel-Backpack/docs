<a name="about"></a>
## About

The Backpack Figma Template helps designers and developers prototype admin panels using Backpack-style screens and components before writing code. Use it to share a design with your team or client and build mockups around familiar Backpack components.

![Backpack Figma Template overview](https://user-images.githubusercontent.com/1032474/128368072-95b9c716-8c8d-4358-ab05-99ff52a9d294.jpg)

<a name="contents"></a>
## Contents

The template includes designs for CRUD operations, fields, columns, filters, widgets and Backstrap UI components, along with an example CRUD that you can duplicate and customize.

![Backpack Figma Template components](https://user-images.githubusercontent.com/1032474/128368095-1da1113b-75c2-4947-8aed-ed4717c53b92.jpg)

> The template is based on the CoreUIv2 theme. The product information states that templates for Tabler and CoreUIv4 are not available, so its appearance will not match those themes.

<a name="usage"></a>
## Usage

1) Obtain access to the template and download the supplied `.fig` file.
2) Create a [Figma](https://www.figma.com/) account and open the file in Figma.
3) Duplicate the example CRUD and adapt the screens and components to your project.

The template is a design resource, not a Laravel package or a source of generated application code.
